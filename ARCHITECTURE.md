# STRANGO Architecture

## Runtime

- `src/`: React application, route components, shared UI, and responsive design system.
- `public/platform.js` and `public/platform.css`: production bundles generated by `npm run build`.
- `server.js`: Express routes, OAuth and email authentication, REST APIs, SEO delivery, and Socket.io.
- `database.js`: application repository with a JSON development store and optional MongoDB persistence.
- `seo-pages.js`: server-rendered SEO landing pages, FAQ schema, and sitemap generation.

## Product Routes

Public discovery:

- `/`
- `/communities` and `/communities/:slug`
- `/discussions` and `/discussions/:slug`
- `/live`
- `/rooms`

Personal surfaces:

- `/dashboard`
- `/messages`
- `/notifications`
- `/sparks`
- `/profile`

Personal surfaces return `noindex` metadata. Public routes receive route-specific canonical metadata from Express.

## Identity Modes

- Ghost: five-minute, view-only session.
- Incognito: anonymous participation with private Sparks and achievements.
- Profile: authenticated public identity through Google or passwordless email.

Write APIs reject Ghost sessions with `PARTICIPATION_REQUIRED`.

## Persistence

Local development uses `data/strango-db.json`. When `MONGODB_URI` is present, the same repository hydrates from and mirrors to MongoDB. This keeps route and socket behavior independent from the persistence driver while allowing the domain tables to be split into dedicated collections as traffic grows.

## Realtime

Socket.io is configured with:

```js
transports: ["websocket", "polling"]
```

Anonymous matching, community channels, voice signaling, livestream signaling, and topic-room presence/messages share the same Socket.io server.

## Production

1. Set the variables in `.env.example`.
2. Run `npm ci`.
3. Run `npm run build`.
4. Start with `NODE_ENV=production node server.js`.
5. Put Express behind TLS and a reverse proxy with compression and request limits.

For horizontal scaling, move Socket.io presence to the Redis adapter and split MongoDB snapshots into the documented domain collections.
